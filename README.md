# Perlin noise simulation

Наши первые попытки сделать совместный проект на гитхаб.

>**Perlin noise** (**Шум Перлина**, также иногда **Классический шум Перлина**) — математический [алгоритм](https://ru.wikipedia.org/wiki/Алгоритм "Алгоритм") по генерированию [процедурной текстуры](https://ru.wikipedia.org/wiki/Процедурное_текстурирование "Процедурное текстурирование") псевдо-случайным методом. Используется в [компьютерной графике](https://ru.wikipedia.org/wiki/Компьютерная_графика "Компьютерная графика") для увеличения реализма или графической сложности поверхности геометрических объектов. Также может использоваться для генерации эффектов дыма, тумана и т. д.

Идея: реализовать шум Перлина с возможностью изменения параметров в реальном времени.
